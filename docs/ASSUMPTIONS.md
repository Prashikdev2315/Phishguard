Assumptions made where the PRD is silent or ambiguous.
Each entry has a risk rating (Low / Medium / High).
Medium or High risks are flagged to the team before continuing.

| A-08 | 1 follow-up  | **Playwright over Selenium** for the race harness. Justification: (1) `launch_persistent_context` is Playwright's official Chromium-extension API — no WebDriver overhead; (2) async-first API matches the extension's event model; (3) CDP session on the same context gives `Target.closeTarget` for cold-SW simulation without restarting the browser; (4) `context.route()` gives per-run hit counting without a real HTTP server. Selenium has no equivalent of (3) and (4) without additional libraries. | Low | None. |
| A-09 | 1 follow-up  | The race harness uses **Playwright's `context.route()` intercept** to serve `http://phishguard-spike.test/*` from memory instead of a real HTTP server. This avoids a hosts-file/DNS setup requirement while still placing the non-loopback hostname `phishguard-spike.test` in the browser's URL bar (Playwright intercepts at the network layer, so the URL is real from the extension's perspective). Teams wanting true network-stack measurement should add a hosts-file entry per `docs/SPIKE_RESULTS.md`. | Low | Documented in SPIKE_RESULTS.md. |
| A-10 | 1 follow-up  | `brands.json`, `action_words.json`, and `allowlist.json` are marked `"_status": "PLACEHOLDER"`. They carry seed data only. The real versions are built in Chunks 2 and 4. Any code that reads these files must check `_status` and log a warning if `PLACEHOLDER` is seen in a non-dev run. | Low | Enforced in Chunk 4 feature extraction. |
| A-11 | 1 follow-up  | Cold-worker simulation in the race harness uses CDP `Target.closeTarget` on the service-worker target. Chrome may restart the SW before the next navigation anyway. If the SW is not found (already inactive), the run proceeds as a warm run and is logged accordingly. | Low | Logged per-run in `tools/spike/race_results.json`. |
| A-12 | 2 fix-up 2   | The official Mozilla Public Suffix List snapshot (including the private section) must be placed at `lists/psl.dat` by the user (>= 100 KB, containing `BEGIN PRIVATE DOMAINS`). `get_psl()` and `PSL()` refuse files under 100 KB or missing the private marker. Unit tests in `TestPSLParser` use `PSL.for_testing()`, while `TestPSLWithRealFile` tests `lists/psl.dat` directly. | Low | User places Mozilla snapshot at `lists/psl.dat`. |
| A-13 | 2 fix-up 2   | **Scheme-less skew ruling:** 61.5% of Benign vs 23.6% of Malicious rows in D1 are scheme-less. Prepending `http://` under N-02 would artificially correlate `is_https=False` with Benign. **User ruling:** Adopted rule N-13 — all string-based features are computed on the scheme-stripped normalized URL, and `is_https` is dropped from model features in schema `fs1` (50 features total). Runtime reason code R-10 (`NO_HTTPS`) continues to evaluate the real scheme at runtime (`r.scheme == 'http'`). | Low (settled) | Updated `CONTRACTS.md` (fs1 count = 50, added N-13, R-10 note).
